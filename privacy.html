سياسة الخصوصية وأمان البيانات السريرية

DentAtlas (دنت أطلس) — ميثاق الشفافية الكاملة لحماية بيانات الأطباء والطلاب وامتثال سياسات Google API وبيانات الهوية.

الميثاق الأساسي للخصوصية في DentAtlas

صُمم تطبيق DentAtlas لخدمة أطباء وطلاب طب الأسنان بأعلى معايير الأمان الرقمي: لا إعلانات، لا تعقب تجاري، ولا بيع للبيانات مطلقاً. التطبيق محلي بالكامل (Offline-First) وسجلات المذاكرة تبقى على جهازك، والمزامنة السحابية اختيارية تماماً ومحمية بعزل صارم للسجلات عبر سحابة Supabase.

1. سياسة استخدام بيانات مستخدمي Google (Google API User Data Policy)

عند استخدامك لميزة تسجيل الدخول عبر Google (Google Sign-In) في تطبيق DentAtlas، يتم الوصول حصراً إلى بيانات الهوية الأساسية الضرورية لإنشاء الجلسة وتوثيق حسابك:

نطاقات الصلاحيات المطلوبة حصراً (Minimal Scopes):

  • openid: للتحقق الآمن من هوية الحساب وفق بروتوكول OpenID Connect.
  • https://www.googleapis.com/auth/userinfo.email: لقراءة عنوان بريدك الإلكتروني لربط حسابك وتأكيد التسجيل.
  • https://www.googleapis.com/auth/userinfo.profile: لقراءة الاسم الكامل ورابط الصورة الشخصية لعرضهما في واجهة ملفك الشخصي داخل التطبيق.

إقرار الاستخدام المحدود (Limited Use Disclosure):

يلتزم تطبيق DentAtlas التزاماً كاملاً بسياسة بيانات مستخدمي خدمات Google API (Google API Services User Data Policy)، بما في ذلك متطلبات الاستخدام المحدود (Limited Use requirements):

  • عدم نقل البيانات لأطراف ثالثة: لا نقوم بنقل أو مشاركة أي بيانات يتم الحصول عليها عبر Google مع أي طرف ثالث، باستثناء ما يلزم لتشغيل خوادم المصادقة السحابية المشفرة (Supabase).
  • حظر الاستخدام الإعلاني: لا تُستخدم بيانات مستخدمي Google مطلقاً لأي أغراض إعلانية، أو تسويقية، أو استهداف تجاري.
  • حظر تدريب نماذج الذكاء الاصطناعي: لا تُستخدم بيانات مستخدمي Google أو سجلاتهم الشخصية لتدريب أي نماذج ذكاء اصطناعي عامة أو خوارزميات تعلم آلي (Machine Learning).
  • حظر الوصول غير المصرح: لا يطلب التطبيق ولا يصل إلى بريد Gmail، أو Google Drive، أو جهات الاتصال، أو التقويم، أو أي خدمات أخرى تابعة لـ Google.

2. التخزين المحلي والعمل دون إنترنت (Offline-First)

  • قاعدة بيانات جهازك: يتم تخزين بطاقات التكرار المتباعد (SM-2+)، وجلسات الاختبارات، وبنك الأخطاء، وملاحظات الحالات محلياً داخل قاعدة بيانات SQLite (عبر Drift) على ذاكرة جهازك.
  • الأمان في وضع عدم الاتصال: يعمل التطبيق دون الحاجة لاتصال بالإنترنت، وتبقى بياناتك على جهازك حتى تختار مزامنتها طوعاً.
  • مسح فوري: يوفر التطبيق خياراً مباشراً في الإعدادات لمسح كافة السجلات المحلية (Clear Local Cache) في أي وقت.

3. المزامنة السحابية وحماية البيانات (Cloud Synchronization)

  • سحابة مخصصة ومستقلة: تُدار المزامنة عبر مشروع Supabase سحابي مخصص ومستقل تماماً لـ DentAtlas (المعرف: djbfnaxiimryijixsoys)، وهو معزول بالكامل عن أي مشاريع أو تطبيقات أخرى.
  • أمان مستوى الصفوف (Row-Level Security - RLS): تطبق قاعدة البيانات سياسات RLS حازمة تمنع أي مستخدم من قراءة أو كتابة أي سجلات لا تنتمي إلى معرفه الشخصي الموثق.
  • التشفير أثناء النقل والتخزين: كافة الاتصالات مع الخادم تتم عبر بروتوكول HTTPS المشفر بأحدث معايير TLS.

4. المساعد التعليمي الذكي (AI Companion Data Flows)

  • البيانات المرسلة للذكاء الاصطناعي: عند توجيه استفسار سريري أو طلب شرح لسؤال، يتم إرسال نص السؤال الطبي والسياق الأكاديمي واستفسارك فقط عبر دالة سحابية آمنة (Supabase Edge Function).
  • حماية الهوية (No PII): لا يتم إرسال اسم المستخدم، أو بريده الإلكتروني، أو عنوان IP الخاص به، أو أي بيانات تعريفية شخصية إلى مزودي نماذج الذكاء الاصطناعي (مثل Z.AI أو OpenCode أو Gemini).
  • خصوصية الحالات السريرية: نلزم المستخدمين بعدم إدخال أي أسماء أو هويات لمرضى حقيقيين في استفسارات المساعد الذكي.

5. الخلو التام من أدوات التتبع والإعلانات (Zero Trackers)

نؤكد بوضوح واعتزاز خلو تطبيق DentAtlas التام من:

  • أي شبكات إعلانية تجارية (No AdMob, No Meta Ads, No Unity Ads).
  • أي أدوات تتبع سلوكي أو تحليلي تجاري (No Firebase Analytics, No AppsFlyer, No Mixpanel).
  • أي برمجيات تتبع موقع جغرافي أو جمع بيانات بيومترية.

6. الاحتفاظ بالبيانات وحذف الحساب (Data Deletion)

يحق للمستخدمين في أي وقت حذف بياناتهم المحلية فوراً أو طلب الحذف الكامل لحسابهم السحابي وسجلاتهم من خوادم المنظومة:

للاطلاع على الإجراءات التفصيلية للمسح المحلي أو تقديم طلب حذف السجلات السحابية، يرجى زيارة الصفحة المخصصة: إجراءات حذف الحساب والبيانات.
